# Reference applications

These are bounded integration briefs, not claims of finished LATTICE products.

## 1. Light-aware studio cue

**Goal:** a Signal Cube measures local light and emits one reviewed wired message for a desktop application or local indicator.

**Minimum physical path:** S-L cassette → calibrated sample → core → wired host → receipt.  
**Evidence:** angular response, sample freshness, packet capture and visible fault behavior.  
**Not included:** cloud account, automatic room control or energy-harvesting claims.

## 2. PV material comparison cube

**Goal:** compare S-P optical-stack variants under a controlled source while retaining the same mirrored appearance language.

**Minimum physical path:** source geometry → finished stack → PV coupon → conditioning input → logged voltage/current/temperature.  
**Evidence:** stack ID, I-V sweep, temperature, visual inspection and reassembly record.  
**Not included:** self-powering the cube or outdoor energy claims.

## 3. Surface-temperature provenance

**Goal:** trace a scale-temperature change to a selected S-T cassette, the material lot and a time-stamped fixture record.

**Minimum physical path:** S-T cassette → core sample → host record → quality/unit record.  
**Evidence:** thermal lag, reference comparison and insulation review.  
**Not included:** thermal safety certification or HVAC control.

These three examples map directly to the [M1 Pilot Program](../manufacturing/M1-PILOT-PROGRAM.md) and keep the project’s physical/digital story concrete.
