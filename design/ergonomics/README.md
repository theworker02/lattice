# Human interaction — CONCEPT

Test grip, one-handed insertion, orientation cue, reflected glare, cable release and accessible shutdown with M0 dummies. Display thresholds only on selection/touch, but keep hazardous status and identity visible. Tap/hold/double-tap/slide are research interactions, not working touch firmware. [Microchip's metal-over-cap guide](https://onlinedocs.microchip.com/oxy/GUID-A518B1F1-10E8-4226-B503-D32F3BD7FD4C-en-US-1/GUID-F561B4E3-EBFE-4C6F-BDCE-C16066E9D107.html) describes a specific metal/spacer/sensor construction; it does not establish touch through arbitrary mirror coatings.

For persistent labels, [E Ink bistability](https://www.eink.com/tech/detail/Benefits) allows image retention without display holding power. Controller standby, refresh and illumination still require a budget. Evaluate an exposed reflective label zone; a dark mirror over e-paper can defeat readability. Maintain a printed underside identity regardless of display choice.
