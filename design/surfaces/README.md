# Surface construction — CONCEPT

Separate protective cover, optical coating, adhesive and functional layer in the stack drawing. Protect coating edges from handling and cleaning fluids. Candidate hiding strategies include partial reflectors, dark apertures and translucent diffusers; each sacrifices light or contrast. Touch zones must not share an untested continuous conductive coating. Identify every surface with zone code M/O/D/P/T/H/R from the design authority and a revision-controlled finish coupon.
