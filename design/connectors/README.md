# Connectors — CONCEPT

Use commodity keyed connectors for E1 and separate signal/ID from switched load power. Magnets only assist mechanical alignment; use rated contacts for electrical conduction. Require recess depth, mate/unmate sequence, contact force, wear, strain relief, pin assignment and creepage/clearance appropriate to the final envelope. No selected connector or pinout is released. Review [LatticeLink](../../docs/LATTICELINK.md) before a connector is frozen.
