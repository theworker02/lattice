# Mirror-scale cube concept

The Signal Cube exterior is now a layered skin of overlapping, shield-shaped mirror scales with a separate recessed dark sensing band. This replaces the earlier generic box illustration in the portal.

`mirror-scale-cube.png` was generated with the built-in image-generation tool. It is an industrial-design visualization, not a photograph, production model or performance claim. The final generation prompt is preserved in `mirror-scale-cube.prompt.txt`.

`scale-section.svg` is a separately authored explanatory section. It distinguishes scales, carrier, optical window, baffle/sensor, board and inner frame. It does not specify actual fasteners, dimensions, chosen materials or electrical design. Interactive image callouts describe the same boundaries and the engineering questions they leave open.

The image is the binding appearance reference for the SC-A0 design brief: [mirror-scale manufacturing plan](../../manufacturing/SIGNAL_CUBE_MANUFACTURING_PLAN.md) and [surface-to-core assembly drawing](../../manufacturing/drawings/signal-cube-core.svg). They assign small optical/PV/temperature cassettes under selected scales and place the controller, protected power and wired interface in an internal central core visible at the dark middle band. This is a reviewed-design starting point, not manufacturing-ready CAD.

`solarskin-stack.svg` and `light-environment.svg` are detailed explanatory diagrams for the portal. The first separates protective layer, mirror/window stack, baffle, light/PV cassette, thermal interface, carrier and core connection. The second separates direct illumination, room reflections, status-light cross-talk and heat. Both define what M1 should test; neither supplies a selected material, performance result or production geometry.

The planar M0 CAD remains a separate MIRRORFIELD research fixture. It has not been replaced with or relabeled as a cube manufacturing design.
