# Industrial envelope — CONCEPT

Authority: [design language](../../LATTICE_DESIGN_LANGUAGE.md). M0 uses a static, serviceable chassis and removable optical cover. The enclosure exposes optical, thermal, identification and tactile functions rather than applying a decorative mirror to a generic box. Keep optical service and electrical service separable. Review tabletop stability and wall-mount retention separately. A motion variant must earn additional clearance, cable routing and pinch protection; the static envelope does not prove it fits.
