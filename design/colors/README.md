# Color references — CONCEPT

Graphite #111316; dark optical #151A20; frame #414F5B; silver #B8CCDE; text #E7E9EB; amber #D8B780. These RGB values control software only. Production color needs substrate/finish-specific samples and approved illumination/viewing conditions. A thermal warning includes a pattern, number and label; do not use color alone. No Pantone, RAL, gloss or coating value is committed.
