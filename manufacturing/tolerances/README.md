# Tolerance strategy — CONCEPT

M0 overall envelope target ±0.3 mm is provisional. Use chassis base as proposed datum A, keyed edge as B and adjacent edge as C. Optical flatness, tilt-axis location, contact wipe, magnet gap, gasket compression and backplane pitch need independent tolerances. Accumulate worst-case pitch error across four cells and cable/retention loads. Do not apply M0 printing tolerance to production optical or electrical alignment.
