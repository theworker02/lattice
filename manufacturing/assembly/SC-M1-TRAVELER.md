# SC-M1 pilot build traveler

**CONCEPT template** · One controlled record per cube. Do not use this as a production work instruction until the process is reviewed.

| Step | Required record | Hold point |
| --- | --- | --- |
| 01 Receive | Unit serial, carrier/core revision, scale/cassette lot, optical variant | Stop if parts are untraceable |
| 02 Core fixture | Protected rails, identity, programmed firmware, host loopback | Core must pass before enclosure work |
| 03 Cassette fixture | Location ID, sensor/PV response, flex continuity | Reject/map mismatch before installation |
| 04 Carrier build | Scale row/order, fastening/bonding lot, visual inspection | Photograph apertures and seams |
| 05 Core integration | Flex connector map, strain relief, insulation and thermal interface | Independent peer check |
| 06 Closure | Closure sequence, exterior inspection and service-access check | Stop on scratched window, pinch or uneven seam |
| 07 Final fixture | Power-up, typed route, surface sensor readings, band cross-talk | Attach test record to serial |
| 08 Review | Rework count/time, nonconformance, as-built deviations | Quality disposition before release to pilot set |

The traveler is the bridge between the physical cube and its digital passport. It must record an as-built revision; it must never imply that a concept location map equals a calibrated sensor configuration.
