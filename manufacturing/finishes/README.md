# Finish approval — CONCEPT

Request witness coupons for reflective, optical-black, satin-frame and translucent-guide finishes. Record gloss/view angle, spectral R/T, scratch/fingerprint behavior, haze, adhesion and color shift after cleaning/UV/thermal cycling. Do not approve appearance from screen RGB. Mask bonding zones and document edge protection. Anti-glare texture is a separate optical variant, not a cosmetic substitution.
