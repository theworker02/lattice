# Fixture requirements — CONCEPT

M0: go/no-go envelope and pitch gauge, cover seating and insertion-force fixture. M1: controlled light source, reference detector, goniometer/angle fixture, calibrated spectral measurement, matched PV I-V measurement and thermal logging. E1: low-power identity fixture, programmable source/load, oscilloscope, communication capture and independently operable shutdown.

Every fixture must identify calibration status, sample serial, software version, connections and pass limits. Include dark/blank controls and repeat runs. A fault injection in JavaScript is not a test of the physical protection switch.
