# MIRRORFIELD roadmap

## Primary product: Signal Cube

Prioritize a cube-shaped sensor and local signal hub. The [Signal Cube direction](SIGNAL_CUBE.md) defines the receive → understand → route → explain workflow. The portal now includes a local routing model with averaging, thresholds, destination receipts and expiring offline buffering. The next physical milestone is one real sensor routed through one reviewed wired adapter; cube enclosure engineering follows that electronics/optical envelope. Preserve the planar MIRRORFIELD research fixture as supporting work.

## 0.5 release foundation

SIMULATED: local optical/thermal twin, battery budget, causal replay, fault arbitration, shared rule IR, diagnostic codecs and Observatory. CONCEPT: design language, M0 envelope CAD, material research, electrical/manufacturing package and review request.

## Next: M0 / M1 evidence

Build no-electronics envelope samples; resolve optical aperture and motion clearance. Acquire small coupons only after selecting experiments and budget. Measure R/T/A and contrast with the exact stack. Replace assumed fractions with versioned measurement datasets. Record durability and material scores from actual observations.

## Next phase: M1 manufacturer pilot

Run the [M1 Pilot Program](../manufacturing/M1-PILOT-PROGRAM.md): twelve instrumented cubes, one common central core, removable face carriers, selected light/PV/temperature cassettes and three controlled optical-stack variants. The program asks a manufacturing partner to contribute parametric six-face CAD, carrier/finish/fixture process recommendations, an assembly traveler, a DFM risk disposition and a costed build process. The goal is not a product launch; it is a trustworthy first-article and yield decision backed by the [DVP](../manufacturing/test-jigs/M1-DVP.md).

## Next: E1 transport and protection

Choose a commodity connector and independent ID/power circuitry through engineering review. Implement a real CAN or other selected adapter with discovery fixtures, timestamps, health TTL, identity handling, firmware update trust and branch isolation. Add voltage/current graphs and independent protection tests before any deployment UI.

## Next: ME1 integrated twin

Synchronize physical readings and configurations, distinguish measured/model-estimated values, retain bounded durable recordings, and support replay without sending commands. Add measured battery/thermal models, actuator energy, glare and neighbor occlusion, typed per-port passports, and testable rule compilation for richer units.

## Next: P1 manufacturing review

Review pilot BOM, suppliers, tooling, assembly yield, serviceability, EMC/environmental evidence and true costs. Freeze revisions only after DFM. No IP rating, production readiness, safety qualification or release manufacturing authorization is implied by this roadmap.
